Markdown to Word (.docx)

Paste Markdown or drop a .md file, then download a Word document. The conversion runs in your browser: your text is not uploaded, and this page has no account, no email form and no analytics.

or drop it here

Supported: headings, bold/italic/strike/highlight, links, lists and task lists, tables, code blocks, block quotes and Obsidian-style callouts. Images are not embedded (local files cannot be read here, remote images are not downloaded); a placeholder is written instead.

About this tool. It was built with AI assistance (AI-generated code) and is open source (MIT): source code. It uses the same converter as DOCX Export Studio, a free Obsidian plugin (GitHub). The plugin also has an optional paid Pro version (adds batch export of folders, Word style presets, footnotes, headers and footers) sold on Gumroad: DOCX Export Studio Pro. This web page is free and nothing here needs Pro. We run it to find people who might want the plugin, and we may earn money if you buy Pro.
Check the claim yourself: open your browser's network tab, then convert a file. No requests are made after the page loads. The page's security policy also blocks outgoing connections.
